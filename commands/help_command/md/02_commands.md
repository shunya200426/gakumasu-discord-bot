# コマンド一覧
### ・</gkms nia final_grade:1417467125567848458>
**最終評価値を計算します**

### ・</gkms nia required_score:1417467125567848458>
**それぞれの評価ランクに必要な最終オーディションスコアを計算します**
**追加の引数から評価ランクを選択することも可能です**

### ・</gkms nia get_final_parameters:1417467125567848458>
**最終試験で獲得する最大パラメータを計算します**
**パラメータが上限を超えるラインも確認できます**

### ・</gkms nia final_grade_from_img:1417467125567848458>
**最終評価値を__スクリーンショットから読み取り__計算します**
**入力する画像は以下の3枚です**
- **P手帳 スケジュール画面のスクリーンショット**
- **P手帳 編成画面のスクリーンショット**
- **オーディションのスコアログ画面のスクリーンショット**

### ・</gkms nia required_score_from_img:1417467125567848458>
**それぞれの評価ランクに必要な最終オーディションスコアを__スクリーンショットから読み取り__計算をします**
**入力する画像は以下の2枚です**
- **P手帳 スケジュール画面のスクリーンショット**
- **P手帳 編成画面のスクリーンショット**
